# Website Edit

Use for an existing WEBSITE change.

1. Resolve the current website identity and the exact requested target.
2. Distinguish full replacement, page replacement, section edit, style-only edit, and content-only edit.
3. Preserve unrelated pages, files, behavior, and user content.
4. Treat vague requests as targeted improvements unless the user explicitly requests replacement.
5. Propose the smallest coherent file set and keep approval mandatory.
6. Verify links, responsiveness, domain identity, and preview behavior affected by the change.

Do not reinterpret CODE app identity as WEBSITE identity in a mixed workspace.
