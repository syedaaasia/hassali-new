# Code Build

Use for a new application, API, script, or code system in CODE mode.

1. Resolve requested product identity, stack, runtime, core entities, screens, and acceptance criteria.
2. Prefer the repository's established framework and file conventions.
3. Separate MVP requirements from optional work.
4. Include data flow, failure states, security boundaries, and focused tests.
5. Preserve existing app identity for edits and surface identity collisions for new apps.
6. Produce an approval-first proposal only. Do not install packages or run arbitrary commands.

The existing CODE overwrite guard and preview contract remain authoritative.
