# Website Build

Use for a new WEBSITE artifact or an explicit complete replacement.

1. Preserve the current prompt as the highest-authority product brief.
2. Extract business identity, audience, page count, required pages, style constraints, negative constraints, and requested media behavior.
3. Produce a complete approval-first static website proposal. Do not apply it.
4. Keep visitor copy natural. Put missing business facts in proposal warnings rather than public placeholders.
5. Preserve explicit no-WebGL, no-animation, page-count, and exclusion constraints.
6. Verify required files, navigation targets, responsive layout, preview compatibility, and domain coherence.

The existing WEBSITE planner, validator, repair, and approval policy remain authoritative.
