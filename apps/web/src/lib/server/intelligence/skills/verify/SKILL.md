# Verify

Use direct evidence from the surface the user actually relies on.

1. Define the exact acceptance behavior.
2. Run the narrowest real test that proves it.
3. Capture status, output, headers, rendered state, or other decisive evidence.
4. Add one adjacent regression probe.
5. Distinguish route-verified, browser-verified, code-inspected, and not-verified claims.
6. Report limitations without converting them into success.

Use the evidence-check script when a structured evidence record is requested.
