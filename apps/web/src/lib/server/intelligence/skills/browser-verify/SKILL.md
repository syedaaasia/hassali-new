# Browser Verify

Use the real browser surface for rendered and interactive behavior.

1. Open the exact route under test.
2. Check visible content, interaction, navigation, console errors, and network failures.
3. Test a representative desktop and mobile viewport when layout matters.
4. Check canvas dimensions and nonblank pixels for WebGL or Canvas experiences.
5. Reload and navigate to expose duplicate lifecycle or stale-state defects.
6. Capture screenshots or observations as evidence and remove temporary fixtures.

Do not bypass authentication or treat source inspection as browser verification.
